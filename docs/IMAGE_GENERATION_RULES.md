# HINK 图集图片生成规范

本规范用于生成可以直接收录到 HINK 电子纸项目内置图集的图片。

## 1. 固定成品格式

- 格式：PNG
- 尺寸：`500×244 px`
- 宽高比：严格 `250:122`
- 色彩：RGB
- 透明通道：不使用；使用白色背景
- 单文件大小：不超过 `300 KiB`
- 收录目录：`site/assets/gallery/`

`500×244` 是项目当前图集采用的 2× 成品尺寸。项目脚本允许 `250×122`，但默认统一使用 `500×244`，方便保留文字和图形边缘细节。

## 2. 画面约束

价签是黑、白、红三色电子纸，生成内容应优先适应固定像素和有限色板：

- 以白色背景为主。
- 主要使用黑色和电子纸红色表达文字、图形和重点。
- 保持高对比和清晰轮廓。
- 优先使用大色块、粗线条、简洁构图和较大的文字。
- 避免复杂渐变、柔和阴影、透明叠加、细密纹理和低对比灰色文字。
- 可以保留少量抗锯齿边缘，但不要依赖灰阶表现细节。
- 红色应作为强调色使用，不要让大面积红色承载过多细小信息。

项目网页发送图片时会再次将画面量化为黑、白、红三色。图片本身越接近这三种显示颜色，网页预览和实际价签效果越一致。

## 3. 构图建议

生成前先按横向电子纸画面设计，不要先按普通海报或手机屏幕设计：

- 重要内容放在安全边距内，四周建议保留约 10–16 px。
- 文字尽量使用粗体、无衬线字体或明显的块面字形。
- 一张图只表达一个主要主题或一句主要信息。
- 让黑色负责主体结构，让红色负责强调、标记或局部视觉焦点。
- 避免把关键文字放在过窄的边缘区域。
- 生成后应按 `250×122` 的实际显示比例检查一次，确认缩小后文字仍然可辨。

## 4. 文件命名与图集登记

文件名使用英文小写 slug，只允许字母、数字和连字符，例如：

```text
morning-focus-red.png
weekend-sale.png
calm-mind.png
```

文件放入 `site/assets/gallery/` 后，需要运行：

```sh
python3 scripts/build-gallery.py
```

脚本会检查尺寸比例、文件大小、文件名和图片总数，并重新生成 `site/assets/gallery/manifest.json`。新图片还需要在 `site/assets/gallery/catalog.json` 中登记标题和分类。

也可以使用 [图集制作器](../site/gallery-maker.html)（`site/gallery-maker.html`）在浏览器中完成图片处理和保存：上传图片 → 调整构图 → 预览三色效果 → 选择本地图集目录保存。制作器会自动更新 `catalog.json` 和 `manifest.json`。

## 5. 推荐生成流程

1. 按本规范生成横向黑白红视觉稿。
2. 将成品整理为 `500×244` 的 RGB PNG。
3. 确认没有透明通道，文件大小不超过 `300 KiB`。
4. 用 `250×122` 的缩小预览检查文字、线条和红色区域。
5. 将文件命名为英文小写 slug 并放入图集目录。
6. 运行图集校验和项目测试。

如果生成工具输出了其他尺寸或带有透明通道，应在收录前统一裁切、缩放、铺白底并转换为本规范的 PNG 成品；不要直接把未经整理的生成结果放入图集。

## 6. 可复用生成模板

以后生成新图时，可以先按下面的模板补充目标内容：

```text
为 HINK 2.13 英寸黑白红电子纸生成一张横向画面。

画布比例：250:122，最终输出 500×244 px RGB PNG，白色背景，无透明通道。
视觉限制：只使用高对比的白、黑、红三色；避免渐变、阴影、灰阶、透明叠加和细密纹理。
构图要求：重要内容距离边缘约 10–16 px，主体轮廓清晰，缩小到 250×122 后仍易辨认。
主要主题：<填写主题>
需要出现的文字：<填写文字；如无则写“无文字”>
黑色内容：<填写主体结构>
红色内容：<填写强调区域>
整体气质：<填写简洁、警示、节日、励志等方向>
文件名 slug：<填写英文小写文件名>
```
