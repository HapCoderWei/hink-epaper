## 独立固件身份

- 编译面板档案：`HINK_PANEL_PROFILE=2`
- OTA Board ID：`0x2198`
- 首个候选内部版本：`20`
- 候选文件：`HINK_GDEY0213Z98_V20.bin`

独立 Board ID 用来阻止原 HINK 面板和 SSD1680 面板通过网页 OTA 相互误刷。当前网页图像缓冲仍是 8000 字节：前 4000 字节黑层，后 4000 字节红层。

## SSD1680 候选序列

- BUSY 高电平表示工作中，低电平表示就绪。
- 硬复位高/低/高：20 ms / 2 ms / 20 ms。
- `0x12` 软件复位并等待 BUSY 就绪。
- `0x01: F9 00 00` 设置 250 行；`0x11:03` 设置 RAM 写入方向。
- `0x44:00 0F`、`0x45:00 00 F9 00` 设置 128×250 RAM 窗口。
- `0x4E/0x4F` 把写入位置置零；`0x3C:05` 设置边框；`0x18:80` 使用内部温度传感器；`0x21:80 80` 设置显示更新控制。
- `0x24` 写入 4000 字节黑层，`0x26` 写入 4000 字节红层，`0x20` 启动刷新。
- 刷新完成且 BUSY 回到低电平后，发送 `0x10:01` 深度休眠。
